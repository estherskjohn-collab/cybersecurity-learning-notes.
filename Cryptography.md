🔐 CRYPTOGRAPHY – THE FOUNDATION OF DIGITAL SECURITY

1. Introduction

Cryptography is the science of protecting information using mathematical techniques and algorithms.

It converts readable information into an unreadable format to prevent unauthorized access.

2. Important Terminologies

- Plaintext: Original readable message.
- Ciphertext: Encrypted unreadable message.
- Encryption: Converting plaintext into ciphertext.
- Decryption: Converting ciphertext back into plaintext.
- Cryptographic Key: A value used by a cryptographic algorithm.

3. Types of Cryptography

A. Symmetric Encryption

- Uses the same secret key for encryption and decryption.
- It is generally fast and suitable for large amounts of data.
- Example: AES.

B. Asymmetric Encryption

- Uses a pair of mathematically related keys.
- Public Key: Can be shared with others.
- Private Key: Must be kept secret.
- Example: RSA.

4. Hash Functions

A hash function converts input data into a fixed-length hash value.

Examples:

- SHA-256
- SHA-512
- MD5 (not recommended for security-sensitive collision-resistance applications).

Uses:

- Data integrity verification.
- Secure password storage using dedicated password-hashing algorithms.
- Digital signature processes.

5. Digital Signatures

Digital signatures help verify:

- Authenticity
- Integrity
- Non-repudiation

They use cryptographic keys and signature algorithms to verify the origin and integrity of digital information.

6. Key Exchange

Key exchange allows two parties to establish a shared secret key over an insecure communication channel.

Example: Diffie–Hellman Key Exchange.

7. Real-World Applications

- HTTPS secure communication.
- Online banking.
- Secure messaging.
- Digital certificates.
- Software verification.

8. Conclusion

Cryptography is an essential part of cybersecurity. It helps protect the confidentiality, integrity, and authenticity of digital information.
